## Setup & Run

**1. Clone the repository**
```bash
git clone https://github.com/paras-banshkar/APTCODER-ML-Assignment.git
cd APTCODER-ML-Assignment
```

**2. Install dependencies**
```bash
pip install -r requirements.txt
```

**3. Launch Jupyter Notebook**
```bash
jupyter notebook APTCODER_ML_Assignment.ipynb
```

**4. Run all cells**

In Jupyter: `Kernel → Restart & Run All`
